# ADR-010: bundled JavaScript formatting in a cancellable worker

Status: selected for the first formatter adapter; Python/Ruff, C#/Roslyn and Windows acceptance remain open.

Use pinned Prettier 3.10.1 standalone with only its Babel parser and ESTree printer, bundled into `dist/formatter.worker.js`. The formatter runs in a fresh browser worker for each explicit Format/Alt+Shift+F/Format script command. It parses source as data, never evaluates it, loads workspace configuration, runs hooks or installs dependencies. Embedded-language formatting is disabled; no external plugins, executable paths or network resources are accepted. See the primary [standalone API documentation](https://prettier.io/docs/browser). No workspace/host protocol or portable schema change is needed.

Input is valid Unicode with a UTF-16 cursor offset and at most 256 KiB UTF-8; output has the same byte cap. Whole-document options are fixed: 80 columns, two spaces, semicolons, double quotes, trailing commas, bracket spacing, always-parenthesized arrows and input newline convention (`auto`). Formatting can intentionally normalize layout and quote style. BOM, shebang and code/string/comment content are covered by regression checks. The primary cursor is mapped with `formatWithCursor`; multiple selections collapse to that cursor after a changed format. Undo restores the prior text/selections. Exact scroll/cursor accessibility across platforms remains acceptance work.

The renderer client permits one request, correlates exact bounded result shapes, has a five-second deadline, and terminates the worker after success, failure, cancellation or timeout. Unmount also cancels outstanding work. No persistent formatter process or hidden retries exist. Missing assets/worker startup errors leave editing available. Cancellation status is emitted only when a request was still pending, so a late click cannot describe applied text as cancelled.

The existing foreground-operation lock drains pending recovery writes and keeps editor controls read-only while the worker runs; Cancel format remains available. Before applying a result, verify model identity, active script ID, language and model version. A stale result is discarded. Apply changed text through the Monaco model edit/undo API with explicit undo boundaries; this works while interactive editing is locked. No-op formats create no edit/undo entry. Independent name/folder/language and classification drafts are retained, and canonical files change only on an explicit subsequent Save. Formatting never implicitly adopts external source changes.

Prettier's package license is MIT. Retain its complete LICENSE and THIRD-PARTY-NOTICES.md (covering bundled MIT/BlueOak/ISC/BSD/Apache dependencies) under `dist/licenses/prettier` on every build. The existing portable dist allowlist carries worker/assets/notices without copying node_modules or exposing the CLI. The dependency lock pins the registry artifact/integrity. A local production-dependency audit reported zero known advisories at this batch's check; this is not full release/dependency acceptance.

Show editing, formatting and execution capabilities independently. JavaScript formatting is bundled; Python/C# formatting and all runners remain unavailable. Highlighting/formatting do not establish an executable runtime. Worker separation bounds formatter reliability; it does not sandbox future user-script execution, which uses the user's OS permissions. Windows/package/clean-machine, parser stress/cancel timing, full accessibility and remaining formatter acceptance remain open.

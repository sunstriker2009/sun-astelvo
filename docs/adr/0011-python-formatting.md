# ADR-011: bundled Ruff WebAssembly Python formatter

Status: selected for Python formatting; C#/Roslyn and Windows acceptance remain open.

Pin `@astral-sh/ruff-wasm-web` 0.17.5 and compile its web bindings plus WASM bytes into `dist/python-formatter.worker.js`. Use `initSync` with those bundled bytes, not runtime fetching. This needs no Python interpreter, native Ruff executable, workspace config discovery, dependency installation or network access. Ruff parses/formats source data and never executes Python. The upstream [WASM API](https://github.com/astral-sh/ruff/blob/0.17.5/crates/ruff_wasm/README.md) is experimental, so the exact version/integrity and regression tests are required for upgrades.

Select JavaScript or Python through a narrow renderer-side adapter choice. Each uses its own fresh worker but the shared exact request/result contract, UTF-8/Unicode/cursor bounds, five-second deadline, cancellation, stale-result guard and model undo integration from ADR-010. Unsupported languages are rejected. No host IPC/workspace schema change or arbitrary executable/path/config input is added. The existing renderer CSP, sandbox/context isolation and network restrictions are unchanged; the real Electron worker initialized and formatted successfully under them.

The Python adapter constructs a Ruff Workspace with fixed stable options: line length 88, four-space indentation, target Python 3.10, preview disabled, double quotes, automatic input newline convention and no embedded docstring-code formatting. Preserve a leading UTF-8 BOM explicitly. Both source and output retain the 256 KiB UTF-8 limit. Errors return bounded first-line diagnostics and no partial text. Rust Workspace allocations are freed in `finally`; the outer client terminates the worker on completion, failure, cancellation or deadline.

Ruff's WASM format API returns text without cursor source maps. Preserve the primary cursor exactly within a common unchanged prefix/suffix; otherwise keep a bounded line/column approximation in the formatted document. This is less precise than Prettier's cursor map and is documented rather than presented as token tracking. Changed formats still collapse multiple cursors to one; Undo restores prior text/selections. Source hashes, name/folder/language and unsaved label/favourite drafts remain independent; only explicit Save commits canonical state.

The package declares MIT and includes LICENSE/README source/version notices. Copy both unchanged into `dist/licenses/ruff` on every build; portable staging carries those and the self-contained worker, excluding node_modules. The current worker is about 13.5 MB because the roughly 10 MB WASM binary is embedded as data. It is loaded only on explicit Python Format. Complete compiled Rust dependency/license inventory and Windows cold-start/memory/deadline acceptance remain M5 gates; retaining the upstream package licence is not claimed as a full compiled-dependency audit.

Editing/formatting/execution capabilities remain separate: bundled Ruff does not establish an installed Python runtime or runner. C# formatting and every script runner remain unavailable. No renderer policy was relaxed. Worker separation is a formatter reliability mechanism, not a sandbox for future scripts, which run with user OS permissions. Windows/package/clean-machine, real stalled-WASM cancellation, precise cursor/accessibility and remaining M1–M5 acceptance stay open.
